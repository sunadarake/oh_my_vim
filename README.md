# Oh My Vim

Vimの初期設定を自動化するプロジェクト

## セットアップ方法

```bash
# Linux
./setup_linux.sh

# macOS
./setup_mac.sh

# Windows
./setup_win.ps1
```

## 使用しているプラグイン

- **SnipMate** - スニペット機能
  https://github.com/garbas/vim-snipmate

- **vim-addon-mw-utils** - SnipMateの依存ライブラリ
  https://github.com/MarcWeber/vim-addon-mw-utils

- **tlib_vim** - SnipMateの依存ライブラリ
  https://github.com/tomtom/tlib_vim

- **vim-smartpairs** - 括弧の自動補完
  https://github.com/gosukiwi/vim-smartpairs

## テーマ

- **atom-dark-256** - Atomエディタ風のダークテーマ
  https://github.com/gosukiwi/vim-atom-dark
