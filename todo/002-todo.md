# setupスクリプトの経過をstdoutで分かりやすくする

## 概要
各setupスクリプトが何をしているかを、ステップ番号つきのメッセージで標準出力に表示する。

## 調査結果
- `setup_linux.sh` と `setup_mac.sh` は同一内容(同一に保つ)
- `setup_win.ps1` も同じ流れ(ディレクトリ作成 → テーマDL → .vimrcコピー)
- 現状はスキップ時と最後の完了メッセージのみ出力。curlの進捗も出る

## 実装計画
- [x] ステップ1: setup_linux.sh / setup_mac.sh に `[1/3]` 形式の経過表示を追加し、curlは `-sS` で静かにする
- [x] ステップ2: setup_win.ps1 にも同じ形式の表示を追加し、New-Itemの出力を抑える

## テスト・確認方法
- [x] `sh -n` と diff で linux/mac が同一であること
- [x] HOMEを一時ディレクトリにして setup_linux.sh を実行し、出力を確認(.vimrcコピー確認)

## 決定事項
- 表示形式は `[n/3] 内容...` と完了時の `完了:` 行
